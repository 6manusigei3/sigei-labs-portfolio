FLAGSHIP // 02 · CASE STUDY

AegraX

A deny-by-default governance platform that treats AI agents as identities with explicit permissions, policy, runtime controls, risk, approvals, audit evidence and detection.

15-phase V1170 service testsNext.js + FastAPIPostgreSQL
THE QUESTION

If an AI agent can act, what proves it was allowed to?

AegraX models agents as first-class principals rather than anonymous automation. Identity, authorization, policy, runtime credentials, approvals, risk and audit evidence are connected into one enforcement path.

ENFORCEMENT PATH
Agent Identity→Permission→Policy→Gateway→Risk→Approval→Audit
CORE CAPABILITIES

Agent registry

Permanent agent identities with tenant ownership, lifecycle and governance metadata.

Exact permissions

Deny-by-default grants with no wildcard or implicit authorization.

Deterministic policy

Deny-only policy evaluation with stable ordering and fail-closed behavior.

Runtime gateway

Agent credentials, replay protection, idempotency and deterministic request evidence.

Tamper-evident audit

Per-tenant HMAC-SHA256 audit chains with integrity verification and export.

Security operations

Risk, approvals, detections, incidents and AI-assisted security analysis.

ENGINEERING PRINCIPLES
  • Deny by default
  • Fail closed on corrupt or missing security state
  • Human approval where risk requires it
  • Evidence for decisions and runtime actions
  • Tenant isolation across control planes
