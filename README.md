# Sigei Labs X

Sigei Labs X is Emmanuel Kipchumba Sigei's portfolio for cybersecurity, AI security, secure software and systems engineering.

The site presents flagship security platforms, full-stack systems, distributed-system experiments, OSINT tooling, blockchain work and the engineering progression behind them.

## Live site

GitHub Pages:

`https://6manusigei3.github.io/sigei-labs-portfolio/`

## Site structure

- `index.html` — portfolio overview and featured systems
- `projects.html` — flagship case studies, project library and repository archive
- `journey.html` — engineering progression and capability areas
- `about.html` — profile, current technical direction and contact information
- `app.js` — project data, filters and flagship project modals
- `site.js` — shared navigation and interaction behavior
- `styles/` — responsive visual system and page-specific styling
- `logo-slx.svg` — primary SLX brand mark
- `favicon.svg` — browser icon

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Portfolio focus

The strongest work centers on security engineering principles including identity, authorization, tenant isolation, auditability, evidence integrity, defensive detection, reliable asynchronous workflows and responsible AI controls.

Public project cards link to their corresponding GitHub repositories. NexoraX, AegraX and SentraX are documented portfolio builds and are presented without public repository links where the source is not public.
