# Sigei Labs Portfolio

A static, dependency-free portfolio website built from Emmanuel Kipchumba Sigei's public GitHub repositories plus documented private/local flagship projects.

## Run locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

You can also double-click `index.html`, although the local server is recommended.

## Files

- `index.html` — site structure
- `styles.css` — complete visual system and responsive styling
- `app.js` — project data, filters, modal case studies and interactions
- `favicon.svg` — SLX browser icon

## Notes

- No GitHub repository was modified to create this website.
- Public repository links open the original GitHub repositories.
- NexoraX, AegraX and SentraX are presented from the documented portfolio project history and are not linked to public GitHub repositories here.
